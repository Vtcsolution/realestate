# VIP Estates — Luxury Real Estate Demo

A full-featured luxury real-estate marketing site built with React 19, Vite, and Tailwind CSS v4.

## Features

- Sticky glassmorphism navbar with animated hover underlines, mobile drawer menu, and a scroll-to-top page transition system
- Home page with a full search hero (Buy/Rent/Sell/Manage tabs, dual-range price/area sliders, amenities filters), featured property carousel, and testimonials
- Properties listing with sidebar filters, sorting, and pagination
- Property details page with an image gallery + lightbox carousel, floor plan chart, amenities, nearby landmarks, and a dedicated Property Report page
- Agents directory, Services (alternating feature rows), Testimonials, FAQ, and a full Blog with per-post detail pages
- Contact form with validation and toast feedback
- Floating AI chatbot widget with a persistent greeting bubble, plus a WhatsApp quick-contact button
- Fully responsive, code-split routes, and SEO meta tags per page

## Tech Stack

- React 19 + React Router v6
- Vite
- Tailwind CSS v4
- Framer Motion
- Swiper
- Recharts
- lucide-react

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
